[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

Fast, private, and local document processing with zero size limits.

> 🌐 **Prefer a Web UI?** Use the free online browser tool at **[https://pdfjin.com/pages/pdf-to-word.html](https://pdfjin.com/pages/pdf-to-word.html)**.

---

## 📦 Installation

```bash
pip install pdfjin-pdf-to-word
```

Or install from source:

```bash
git clone https://github.com/pdfjin/pdfjin-pdf-to-word.git
cd pdfjin-pdf-to-word
pip install .
```

---

## 🚀 Quickstart

Run via CLI:
```bash
pdfjin-pdf-to-word --help
```

Use in Python:
```python
import pdfjin_pdf_to_word
```
